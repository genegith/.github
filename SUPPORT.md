# Support

Use the support channel provided by the individual repository when one is documented.

Before asking for help:

1. Read the repository README and other documentation.
2. Search existing issues for the same question or problem.
3. Remove credentials, tokens, personal information, and other sensitive data from examples and logs.

If no project-specific channel exists, open an issue in the affected repository and provide the goal, relevant environment or version, steps already tried, expected behavior, and any sanitized error output.

Use the bug-report form for reproducible defects and the feature-request form for proposed improvements. Security vulnerabilities must follow `SECURITY.md` and must not be reported publicly.

Support is provided on a best-effort basis; response times are not guaranteed.
