# Contributing

Thank you for contributing to a `genegith` project.

## Before you start

- Search existing issues and pull requests before opening a duplicate.
- Use the repository's issue templates when reporting a bug or proposing an enhancement.
- For substantial or potentially breaking changes, open an issue first so the approach can be discussed.
- Never include credentials, tokens, private keys, customer data, or other sensitive information.

## Make a change

1. Fork or clone the repository and create a focused branch from its default branch.
2. Follow the repository's existing structure, naming, formatting, and testing conventions.
3. Keep commits and pull requests focused on one logical change.
4. Add or update tests and documentation when behavior changes.
5. Run the relevant checks and record the results in the pull request.

## Open a pull request

Complete the pull request template with the reason for the change, validation performed, operational impact, and rollback steps when relevant. Link related issues and call out anything reviewers should examine closely.

Repository-specific contribution instructions take precedence over this default guidance.
